# Triage labels

| Role | Label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer must evaluate |
| needs-info | needs-info | Waiting for information |
| ready-for-agent | ready-for-agent | Specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use these labels when skills name a canonical triage role.

Milo's execution labels remain separate. `ready-for-agent` does not replace or automatically grant `milo:ready` execution approval.
